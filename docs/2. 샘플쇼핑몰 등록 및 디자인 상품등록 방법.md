**자주 막히는 곳**

| 막힘 | 해결 |
|---|---|
| jsDelivr 403 `Package size exceeded … 50 MB` | 저장소(그 커밋 전체)가 50MB 초과. 원본 사진은 `git rm --cached` + `.gitignore`. 확인 `git ls-tree -r -l HEAD \| awk '{s+=$4} END {print s/1048576}'` |
| 샘플몰 이미지 주소에 pg 번호가 없다 | 정상. 샘플몰은 `https://<샘플몰>.cafe24.com/<폴더>/<파일>` 로 바로 열린다 (2절) |
| `git push` 가 멈추거나 `/dev/tty` 오류 | PowerShell 에서 `$env:GCM_INTERACTIVE = "always"; git push …` (로그인 창이 뜨면 로그인) |
| "사람인지 확인"(veritas-hub challenge) 화면 | 짧은 시간 요청이 많을 때. 사람이 직접 통과. 자동 캡처(headless)는 **공개 화면만** 쓴다 |
| 편집 창 캡처가 안 된다 | 편집 창은 로그인 필요 + [고치기]로 만든 초안(localStorage)이 있어야 뜬다 → 10-2 |
| 긴 페이지 한 장 캡처가 반복돼 보인다 | Chrome 은 16,000px 넘는 캡처를 되풀이해 그린다 → 스크롤하며 조각으로 (10-5) |
| 파트너센터 이미지가 저장 안 됨 | 파일 칸에 넣고 `change` 를 쏘면 칸이 비워진다 → 파일만 넣고 change 없이 [임시저장] (11-3) |
| 태그가 한 칸에 다 들어간다 | 하나 쓰고 Enter, 하나 쓰고 Enter (11-4) |
| [임시저장] 뒤 "비밀번호 확인" 화면 | 정산 정보가 비어 있어서. 사람이 입력 (11-6). 저장 자체는 된다 |
| 샘플몰 쇼핑몰 이름이 안 바뀜 | "대표 전화 항목이 비었습니다" → 대표 전화부터 (9) |
| **상세페이지에 `?edit=1` 를 쓰면 안 됨** | **영업 비밀.** "구매 후 알려 드리는 관리자 전용 주소"라고만 쓴다 |

## 10. 디자인센터 상세페이지 만들기

PETPIA 상세페이지(`D:\pet\…\petpia-designcenter-detail.html`)와 **같은 구성**으로 만든다.
히어로 → **구매 후, 이렇게 쉽게 바꿔요**(3단계 + 섹션 15개 : 화면 ↔ 편집 창) → 작업 진행 절차(+주문서 버튼) → 바로가기 → 소개 → 세일 · 카운트다운 → 이벤트 2칸 → 쿠폰 뽑기 → 타임세일 → 운영 편의 3종 → 탐색 3칸 → 상품 탐색 → 구매 전 안내 → 포토리뷰 → 디자인 소개 → 마무리(샘플 사이트) → 푸터

> ⚠ **`?edit=1` 는 영업 비밀.** 상세페이지 · 이미지 · alt 어디에도 쓰지 않는다. "구매 후 알려 드리는 **관리자 전용 주소**로 쇼핑몰을 열면…" 으로 쓴다.
> 캡처에 주소창이 나오지 않게 한다 (headless 캡처는 주소창이 없다).

### 10-1. 공개 화면 캡처 (로그인 불필요)

편집 모드(`?edit=1`)의 [고치기] 버튼 · 편집 막대는 **로그인 없이도 보인다** → puppeteer(headless)로 샘플몰을 찍는다. 로그인한 사람의 쿠키를 도구로 옮기지 않는다.
- 애니메이션을 끄고(`*{transition-duration:0s!important;animation-duration:0s!important}`), 첫 화면 영상은 `pause(); currentTime = 0.9`
- **캡처 탭을 앞으로** (`bringToFront`) — 뒤에 있는 탭은 캡처가 멈춘다
- **보기 창 크기를 바꾸지 않는다** — 화면 높이(vh)로 크기가 정해지는 섹션이 밀린다 (1200×1240 고정)
- 아주 긴 페이지에서 `clip + captureBeyondViewport` 는 시간 초과 → 섹션 위치로 스크롤 → 보이는 화면을 찍고 ffmpeg 로 잘라낸다
- 첫 화면(스크롤 연출)은 **맨 처음, 끝까지 스크롤하기 전에** 찍는다
- 숨김 섹션(높이 0)은 캡처 때만 잠깐 보이게 한다

### 10-2. 편집 창 가져오기 (로그인한 브라우저)

편집 창은 게시판 2번 글쓰기 화면 위에 뜬다. 조건 : ① 관리자 로그인 ② 편집 모드에서 [○○ 고치기]를 눌러 **초안**(`localStorage` `<브랜드>-cms-draft`)이 있을 것.
1. 로그인한 브라우저 탭에서 `https://<샘플몰>/?edit=1` → 콘솔 :
   ```js
   window.open = () => null;   // 새 탭 막기
   for (const b of [...document.querySelectorAll('.cms-btn')].filter(x => /고치기/.test(x.textContent) && !/카카오/.test(x.textContent))) { b.click(); await new Promise(r => setTimeout(r, 400)); }
   ```
2. 같은 탭에서 섹션마다 숨긴 iframe 으로 `/board/free/write.html?board_no=2&cms=<영역 이름>` 을 열고 `.pcms` 를 복제 (textarea 는 `textContent = value`, input 은 `value` 속성으로) → 18개를 한 번에 `JSON.stringify` 로 돌려받으면 결과가 커서 파일로 저장된다 → `_deploy/dc/editors.json`
