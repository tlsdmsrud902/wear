# WEARPICK(wear902) 판매 실행 계획 — 2026-10-03

목표 : **한 달 매출 200만 원** · 광고비 하루 1만 원 · 오래 걸리는 작업은 하지 않고 바로 효과가 나는 일만 한다.

```
200만 원 = 단순복사 220,000 × 9건
        = 커스터마이징 390,000 × 3건 + 단순복사 220,000 × 4건 (≈ 205만)
        = 풀세팅 590,000 × 2건 + 커스터마이징 390,000 × 1건 + 단순복사 220,000 × 2건 (≈ 201만)
(판매 수수료 빼기 전 금액)
```
→ 건수를 늘리는 것보다 **비싼 옵션을 고르게 만드는 것**이 빠르다.

## 4. 돈 안 드는, 오늘 바로 할 일

1. **크몽 의뢰 요청에 제안 넣기** : "카페24 쇼핑몰 제작 · 리뉴얼 · 스킨" 요청 글에 매일 제안. 이미 돈 쓸 사람에게 가는 가장 빠른 길
2. **문의 1시간 안에 답하기** : 디자인센터 · 크몽 문의 알림을 휴대폰으로 켠다. 답이 늦으면 다른 스킨을 산다
3. **첫 구매자 3명** : 설치를 1:1로 끝까지 도와주고 → 후기 + 적용 사이트 등록 동의를 받는다 (실제 후기만, 지어낸 후기 금지)
