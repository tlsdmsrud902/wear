## 1. 무엇을 하는 기능인가

손님이 오른쪽 아래 검은 말풍선을 누르면

```
첫 화면 : 인사말 + 메뉴 (01 배송 안내 · 02 교환·반품·환불 · 03 상품 상담 · 04 쿠폰·이벤트 · 05 주문·결제 · 06 회원·적립금 · 07 자주 묻는 질문 · 08 상담원 연결)
   ↓ 메뉴 선택
그 분류의 질문 목록 (Q. …)          ← 질문이 하나뿐인 메뉴(상담원 연결)는 바로 안내
   ↓ 질문 선택
안내 내용 + 바로가기 버튼(주문 조회 · 쿠폰함 …) + 같은 분류 다른 질문 + [처음 메뉴]
```

- 메뉴에 없는 질문은 아래 입력칸에 직접 물어본다 → 가장 가까운 답 / 「이걸 찾으셨나요?」 / 상품 검색 · 상담원 연결
- **AI · 외부 서비스 · 월 이용료 없음.** 사장님이 적어 둔 내용으로만 답한다 (틀린 답을 지어내지 않음)
- 상담원 연결 = **카카오톡 채널 1:1 채팅(실시간)** + 문의 게시판 (A+B 방식, 11절)

### 판매 포인트 (상세페이지 · 광고 문구)
- 「월 이용료 없는 쇼핑 도우미 기본 탑재 — 배송 · 교환 · 사이즈 질문은 도우미가 먼저 답해요」
- 「카페24 게시판에 글만 쓰면 도우미가 배워요」
- 「채널톡처럼 메뉴형 상담 + 카카오톡 실시간 상담 연결」

## 3. 넣기 · 빼기

### wear902 계열 스킨 (wear-cms.js 화면 편집이 있는 스킨)
`layout/basic/layout.html` — **우측 플로팅 버튼(`#s9Float`) 스크립트 바로 뒤**에 한 줄
```html
<!-- 쇼핑 도우미 (단독 기능 · /addons/shop-helper/) : 빼려면 아래 한 줄을 지운다 -->
<script src="/addons/shop-helper/shop-helper.js?v=20261003i"></script>
```
- 설정은 `store-content.js` 의 `helper` (4절)
- `defer` 를 붙이지 않는다 (편집 모드 연결 순서 때문)

### 그 밖의 카페24 스킨 (단독)
`</body>` 바로 앞에 두 줄
```html
<script src="/addons/shop-helper/shop-helper.config.js?v=1"></script>
<script src="/addons/shop-helper/shop-helper.js?v=1"></script>
```

### 빼기
- 완전히 : 위 줄을 지운다 (폴더는 남아도 영향 없음)
- 잠깐 : `enabled: false` (편집 모드에서는 계속 보임)
- wear 계열에서 빼도 `wear-cms.js` 의 helper 어댑터 · `store-content.js` 의 `helper` 는 그대로 둬도 된다 (도우미 버튼이 없으면 쓰이지 않음)

## 4. 설정 항목 (`SHOP_HELPER_CONFIG` = `store-content.js` 의 `helper`)

| 항목 | 기본값 | 화면 |
|---|---|---|
| `enabled` | `true` | 버튼 보이기 |
| `brand` | 쇼핑몰 이름(og:site_name) · `STORE_CONTENT.brand.name` | 머리글 맨 위 영문 |
| `label` | `Concierge` | 브랜드 옆 작은 글자 |
| `kicker` | `How can we help?` | 머리글 세리프 기울임 |
| `name` | `쇼핑 도우미` | 머리글 큰 제목 |
| `greeting` | `안녕하세요! {brand} 쇼핑 도우미예요.\n궁금한 내용을 골라 주세요.` | 메뉴 위 첫 문장 |
| `hours` | `평일 10:00 – 17:00 (점심 12:00 – 13:00, 주말 · 공휴일 휴무)` | 「지금 상담 가능 / 상담 시간이 아니에요」 계산 (평일 · 점심 반영) |
| `contact` | 페이지의 카카오톡 버튼 주소 → `https://pf.kakao.com/` | 「카카오톡 실시간 상담」 버튼 |
| `askLink` | `/board/product/write.html?board_no=6` | 「문의 남기기」 버튼 |
| `faqBoard` | `3` | 자주묻는질문 게시판 → 「자주 묻는 질문」 메뉴 (0 = 끔) |
| `settingsBoard` | `0` | (단독일 때) 설정 글 게시판 번호 |
| `freeShipping` | `STORE_CONTENT.shipping.freeOver` | 「배송비는 얼마예요?」 답 · `{무료배송}` |
| `couponLink` | 세일 분류가 있으면 그 목록 | [쿠폰 받으러 가기] (없으면 버튼 없음) |
| `couponText` | 공통 문구 | 「쿠폰은 어디서 받아요?」 답 |
| `sizeGuide` | `''` | [사이즈 가이드 보기] (wear : `/#cz-size`) |
| `guideLink` | `''` | [관리 가이드] (wear : `/wear/guide.html`) |
| `colors` | `{ ink:'#111', onInk:'#fff', soft:'#f5f5f5', line:'#ededed' }` | 머리글 · 버튼 / 그 위 글자 / 말풍선 바탕 / 선 |
| `fonts` | `true` | 페이지에 없는 Pretendard · Jost · Fraunces 를 불러옴 |
| `hint` | `true` | 처음 온 손님에게 한 번 「무엇을 도와드릴까요?」(5초) |
| `menu` | 7개 (1절) | 첫 화면 메뉴 「이름 \| 설명」 |
| `qna` | 기본 20개 | **통째로 바꿀 때만** |
| `addQna` | `[]` | 기본에 더하기 · 같은 질문이면 덮어쓰기 · `a:''` 이면 그 질문 끄기 |
| `synonyms` | 기본 12묶음 | 기본 + 설정 + 게시판 글을 **모두 합침** |

**질문과 답 한 묶음** : `{ cat, q, keywords, a, buttons, next }`
- `cat` = 메뉴 이름 그대로 (없거나 메뉴에 없는 이름이면 「그 밖의 질문」)
- `buttons` = 한 줄에 「이름 주소」, 주소 자리에 `{상담}` · `{문의}` 가능
- `next` = 이어서 보여 줄 질문 (`/` 로 구분)
- 답변 안 `{brand}` · `{운영시간}` · `{무료배송}` 자동 치환, `*기울임*`

**기본 질문 20개** : 배송 안내(언제 와요 · 배송비 · 배송 조회) / 교환·반품·환불(방법 · 환불 시점 · 불량·오배송 · 사이즈 안 맞음) / 상품 상담(사이즈 고르기 · 사용·관리 · 재입고 · 상품 문의) / 쿠폰(받는 곳 · 쓰는 법) / 주문·결제(주문 내역 · 취소 · 결제) / 회원(가입 혜택 · 적립금 · 아이디·비밀번호) / 상담원 연결
→ ⚠ 문구(출고 시간 · 교환 7일 · 환불 3~7영업일 · 무료배송 금액)는 **예시**. 구매자 정책으로 고치라고 안내서에 꼭 쓴다.

## 5. 가르치기 — 답이 나오는 곳 (우선순위)

| 순서 | 어디 | 형식 | 메뉴 |
|---|---|---|---|
| 1 | **화면 관리 게시판(2번) 「[모든 페이지] 쇼핑 도우미」 글** (wear 계열 : 편집 창에서 저장) | `이름: …` 줄 + `── 1번 ──` 묶음 | 설정 · 메뉴 · 질문과 답 |
| 2 | 설정 (`store-content.js` / `shop-helper.config.js`) | 4절 | 〃 |
| 3 | 기본값 (코드) | — | 〃 |
| + | **자주묻는질문 게시판(3번)** 글 | 제목 = 질문, 본문 = 답 (+ `키워드:` · `버튼:` · `이어서:` 줄) | 「자주 묻는 질문」 |
| + | 메인 「자주 묻는 질문」 영역 (wear 계열) | 화면 / 메인 화면 관리 기억 | 「자주 묻는 질문」 |
| + | 머리글 분류 메뉴 (`a[href*="cate_no="]`) · 상품 검색 | 자동 | 직접 입력할 때 「○○ 보러 가기」 · 「「○○」 상품 찾아보기」 |

**자주묻는질문 게시판 글 본문 예**
```
반품 상품이 도착해 확인되면 3~7영업일 안에 환불해 드려요.
키워드: 환불, 환불 기간, 돈 언제
버튼: 주문 조회 /myshop/order/list.html
이어서: 교환 · 반품은 어떻게 해요?
```

**설정 글 본문 형식** (단독 스킨에서 `settingsBoard` 를 쓸 때 · wear 계열은 편집 창이 대신 써 줌)
```
보이기: 예
이름: 우리가게 도우미
메뉴: 배송 안내 | 출고 일정 · 배송비
상담원 연결 | 카카오톡 실시간 상담
운영 시간: 평일 10:00 – 18:00
── 1번 ──
분류: 배송 안내
질문: 제주도도 배송돼요?
키워드: 제주, 도서산간
답변: 네, 제주 · 도서산간은 3,000원이 추가돼요.
버튼: 주문 조회 /myshop/order/list.html
이어서: 배송비는 얼마예요?
```
칸 이름 : 보이기 · 이름 · 인사말 · 메뉴 · 못 찾았을 때 · 운영 시간 · 상담 연결 주소 · 문의 남기기 주소 · 배울 게시판 번호 · 같은 말 / 묶음 : 분류 · 질문 · 키워드 · 답변 · 버튼 · 이어서

**읽는 주기** : 설정 글 30분, 자주묻는질문 60분 (손님 브라우저 기억). 편집 모드는 항상 새로. 글 본문은 바뀐 글만 2개씩 차례로 읽는다 (카페24 잦은 요청 차단 회피).

### 같이 고친 화면 관리(wear-cms.js) 안정화 — 다음 프로젝트에도 꼭 반영

3. **손님 목록에서 화면 관리 글 숨기기** (`board/free/list.html` 맨 아래 스크립트)
4. 메인 사이즈 가이드 섹션에 `id="cz-size"` (도우미 버튼 링크)
