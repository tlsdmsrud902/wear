# 쇼핑 도우미 (Shop Helper) — 카페24 스킨 단독 기능

손님이 오른쪽 아래 말풍선을 누르면 **메뉴 → 질문 → 안내 + 바로가기 버튼** 순서로 답하는 상담 창입니다.
AI · 외부 서비스 · 월 이용료가 없고, 사장님이 적어 둔 내용으로만 답합니다.
「상담원 연결」은 카카오톡 채널 1:1 채팅(실시간)과 문의 게시판으로 잇습니다.

| 파일 | 하는 일 |
|---|---|
| `shop-helper.js` | 기능 전부 (화면 · 디자인 · 답 찾기 · 게시판 읽기). 고칠 필요 없음 |
| `shop-helper.config.js` | 사장님 설정 (이름 · 메뉴 · 운영 시간 · 상담 주소 · 질문과 답 · 색) |
| `demo.html` | 카페24 없이 여는 시험 화면 |

---

## 넣기 (3단계)

1. 카페24 관리자 › 디자인 › 디자인 편집(코드 편집)에서 스킨에 **`addons/shop-helper` 폴더**를 만들고 `shop-helper.js` · `shop-helper.config.js` 를 올립니다.
2. `layout/basic/layout.html` 맨 아래 **`</body>` 바로 앞**에 두 줄을 넣습니다.
   ```html
   <!-- 쇼핑 도우미 : 빼려면 아래 두 줄을 지운다 -->
   <script src="/addons/shop-helper/shop-helper.config.js?v=1"></script>
   <script src="/addons/shop-helper/shop-helper.js?v=1"></script>
   ```
3. `shop-helper.config.js` 에서 운영 시간 · 카카오톡 채널 주소(`contact`) · 무료배송 금액 · 기본 안내 문구를 **우리 쇼핑몰 정책에 맞게** 고칩니다.

## 빼기

- **완전히 빼기** : `layout.html` 의 두 줄을 지웁니다. (폴더는 남아 있어도 아무 영향이 없습니다)
- **잠깐 끄기** : 설정의 `enabled: false`

다른 화면 · 기능에는 영향을 주지 않습니다. 저장 공간도 손님 브라우저의 `shop-helper-*` 기억만 씁니다.

## 가르치기 (카페24 안에서)

| 어디서 | 무엇을 | 화면에서 |
|---|---|---|
| `shop-helper.config.js` | 메뉴 · 질문과 답(`addQna`) · 같은 말 · 색 | 첫 화면 메뉴 · 각 메뉴의 질문 |
| **자주묻는질문 게시판** (기본 3번) | 글 제목 = 질문, 본문 = 답 | 「자주 묻는 질문」 메뉴에 자동으로 |
| (선택) 설정 게시판 글 | `settingsBoard` 번호 게시판에 제목 `[모든 페이지] 쇼핑 도우미` | 설정 파일보다 먼저 쓴다 |

**자주묻는질문 글 쓰는 법** — 본문에 아래 줄을 넣으면 더 잘 찾고 버튼도 붙습니다.
```
반품 상품이 도착해 확인되면 3~7영업일 안에 환불해 드려요.
키워드: 환불, 환불 기간, 돈 언제
버튼: 주문 조회 /myshop/order/list.html
이어서: 교환 · 반품은 어떻게 해요?
```

**설정 게시판 글 쓰는 법** (설정 파일을 못 고칠 때)
```
이름: 우리가게 도우미
운영 시간: 평일 10:00 – 18:00
메뉴: 배송 안내 | 출고 일정 · 배송비
상담원 연결 | 카카오톡 실시간 상담
── 1번 ──
분류: 배송 안내
질문: 제주도도 배송돼요?
답변: 네, 제주 · 도서산간은 3,000원이 추가돼요.
```

## 질문과 답 바꾸기

- `addQna` 에 **같은 질문(`q`)** 을 쓰면 기본 답을 바꿉니다.
- `a: ''` (답변을 비움) 이면 그 기본 질문을 끕니다.
- `qna` 를 쓰면 기본 질문 20개를 **통째로** 바꿉니다.
- 버튼 주소에 `{상담}` = 상담원 연결 주소, `{문의}` = 문의 남기기 주소
- 답변 안의 `{brand}` · `{운영시간}` · `{무료배송}` 은 자동으로 바뀝니다.

## 업종 · 색 맞추기

`colors` 의 `ink` 가 머리글 · 버튼 색입니다. 예)
- 흑백(기본) `#111111` · 식품(올리브) `#2f3a28` · 뷰티(로즈) `#7a3e47` · 아기용품(네이비) `#26324a`

## wear902 계열 스킨에서

wear902 스킨(화면 편집 `wear-cms.js` 가 있는 스킨)에 넣으면 자동으로 함께 동작합니다.
- 편집 모드(관리자 전용 주소) 막대의 **[쇼핑 도우미 고치기]** 편집 창에서 메뉴 · 질문과 답을 고칩니다 (게시판 2번에 저장)
- 상담 창의 **교육 모드** : 답마다 출처 표시, 모르는 질문은 [이 질문 가르치기]
- 설정은 `store-content.js` 의 `helper` 를 씁니다 (`shop-helper.config.js` 가 있으면 그쪽이 먼저)

## 알아 둘 점

- 실시간 1:1 상담은 **카카오톡 채널**로 넘깁니다. 상담 창 안에서 사람과 실시간으로 대화하려면 별도 서버가 필요해서 이 기능에는 없습니다.
- 기본 안내 문구(배송 시간 · 교환 기간 · 환불 기간)는 **예시**입니다. 반드시 우리 쇼핑몰 정책으로 고치세요.
- 이 저장소의 원본은 `addons/shop-helper/` 이고, wear902 스킨 안의 `skin1/addons/shop-helper/shop-helper.js` 는 같은 파일입니다. 고치면 둘 다 맞춥니다.
